# Security Policy

## Scope

This repository defines a software-engineering methodology. Security issues in the methodology, automation, templates, or repository configuration are in scope.

## Reporting

Please do not disclose a suspected vulnerability publicly before maintainers have had an opportunity to assess it. Use GitHub's private security reporting mechanism when available.

## Responsible disclosure

Include enough information to reproduce the issue, its impact, affected files/versions, and any suggested mitigation.

## Important

The methodology does not guarantee that software built with it is secure. Security remains risk-based and requires appropriate human review, testing, and independent assessment for higher-risk systems.
