# Security Policy

## Scope

This repository defines a software-engineering methodology. Security issues in the methodology, automation, templates, workflow configuration, or repository configuration are in scope.

This repository also contains guidance for AI/agent security. Claims about AI security should be evaluated against the current applicable OWASP GenAI guidance and other authoritative frameworks.

## Reporting

Please do not disclose a suspected vulnerability publicly before maintainers have had an opportunity to assess it. Use GitHub's private security reporting mechanism when available.

## Responsible disclosure

Include enough information to reproduce the issue, its impact, affected files/versions, and any suggested mitigation.

## Security-sensitive changes

Changes involving:

- security requirements
- CI permissions
- release workflows
- AI agent permissions
- threat-model guidance
- ASVS mappings
- supply-chain controls

should receive explicit security review.

## Important

The methodology does not guarantee that software built with it is secure or compliant. Security remains risk-based and requires appropriate human review, testing, operational controls, and independent assessment for higher-risk systems.
